# Ilustração histórica

`wordpress-modernizer-flow.png` é uma ilustração anterior à revisão documental atual,
mantida como referência histórica. Não representa o fluxo operacional vigente: antecipa
a descoberta do banco, apresenta SFTP como cópia e sugere descoberta de versões de
plugins/temas e remoção de componentes não usados que não existem nesse fluxo.

O diagrama atual está no [README](../../README.md#visão-geral) e a sequência exata em
[operações](../operations.md#ordem-real-da-migração).
